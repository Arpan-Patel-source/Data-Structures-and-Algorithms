## Philosophy

Consistency > intensity.

The objective is not to solve problems for the sake of increasing a number.

The objective is to become better at:

1. Understanding a problem
2. Identifying the underlying pattern
3. Developing an approach
4. Writing a correct solution
5. Analyzing time and space complexity
6. Recognizing better approaches
7. Learning from mistakes
8. Applying the same ideas to new problems

Every solved problem should make the next problem easier.
